# JavaScript + SCAD Library Interop

This repository demonstrates:

- a JavaScript entrypoint
- importing SCAD library modules through `@justinsdk/...`
- taking geometry returned from library modules and continuing with JSCAD transforms and booleans

Suggested linked libraries:

- `JSCAD Modeling`
- `justinsdk`
